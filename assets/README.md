# Fan-art assets

Release sprite sheets and animated previews are original AI-assisted fan-art
interpretations of Ankama characters. They are distributed as part of this
unofficial fan project for installation and review. No general artwork license
or rights to Ankama's characters are granted by this repository's MIT license.
See ../CREDITS.md for attribution. Do not describe these assets as official art.

Local generation intermediates and machine-specific metadata are excluded from
Git. A pet becomes available only after its complete animation package passes QA.
